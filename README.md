# 개미 거래소

친구들과 같은 시장에서 겨루는 모의 주식 게임이에요. 시세는 서버(Supabase)에서 1분마다 움직여서, 아무도 접속하지 않아도 시장이 계속 돌아가요.

## 게임 기능
- 8개 가상 종목, 1분마다 시세 변동, 호재·악재 뉴스, 상한가·하한가(±30%)
- 매수·매도, 평균 단가와 수익률
- 배당금 (게임 속 하루 = 2시간마다 지급, 배당락 적용)
- 은행: 자유 예금, 정기 예금, 적금, 대출 (대출 이자는 은행 수입이 되어 은행이 커져요)
- 1분마다 누를 수 있는 돈벌기 버튼, 상점에서 Lv.20까지 레벨업
- 레벨·칭호·닉네임 색, 업적, 순자산 랭킹

## 구조
- `index.html` 한 파일이 게임 화면 전체예요. GitHub Pages로 배포돼요.
- 데이터와 게임 규칙은 Supabase 프로젝트 `ant-exchange`에 있어요.
  - 매매·은행·돈벌기 같은 모든 동작은 서버 함수(RPC)로만 처리돼서 화면을 조작해도 돈을 만들 수 없어요.
  - `market_tick()` 함수가 pg_cron으로 1분마다 실행돼요.
  - 가입은 `signup` Edge Function이 닉네임 + 비밀번호로 처리해요.

## 참고
- Supabase 무료 플랜은 7일 동안 활동이 적으면 프로젝트가 일시정지될 수 있어요. 그러면 Supabase 대시보드에서 다시 켜면 돼요.
